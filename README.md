# alby.software

Portfolio of Alby McNamara — first-year Immersive Software Engineering student at the University of Limerick.

Built with [Astro](https://astro.build), deployed to GitHub Pages at <https://alby.software>.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
npx astro check  # type check
```
